# LineLess AI Project Instructions

Before modifying this repository:

1. Read docs/MASTER-AI-CONTEXT.md
2. Read docs/PROJECT-MAP.md when understanding project structure.
3. Read docs/DEPENDENCY-MAP.md when changing frontend modules.
4. Read docs/AWS-INFRA-MAP.md before changing AWS infrastructure.
5. Inspect the actual source code before making assumptions.
6. Preserve the existing architecture unless a change is genuinely required.
7. Do not create duplicate functionality.
8. Do not introduce unnecessary dependencies or abstractions.
9. Never use fake/mock functionality in production paths.
10. Preserve security, validation, error handling and accessibility.
11. Run the relevant tests/checks after changes.

LineLess is a real AWS serverless application. Treat the repository as production-oriented code, not a demo/template.
